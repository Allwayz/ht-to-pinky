# ht-to-pinky

Codex skill that converts strict HomeTrans `test_case.md` files into short Pinky test cases.

The skill lives in the `ht-to-pinky/` directory. It contains instructions and a structure checker only. It does not include credentials, account data, or machine paths.

Install it with the Codex skill installer:

```text
repo: Allwayz/ht-to-pinky
path: ht-to-pinky
```
